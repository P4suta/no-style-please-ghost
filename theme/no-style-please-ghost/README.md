# The `no-style-please-ghost` theme

A monochrome reading theme for Ghost 6 with dated archives, single-column articles, and light and dark appearances.

## Installation

Upload the theme ZIP under **Settings → Design & branding → Change theme** and activate **no-style-please-ghost**.

## Publication settings

Use **Heading font** and **Body font** to select a system font or a bundled Japanese font.
A font set in Ghost’s brand typography settings takes precedence.
Enable **Show featured posts** to show up to three public featured articles on the home page.

Ghost uses your primary navigation in the header and your secondary navigation in the footer.
The footer links to the publication feed and the available membership actions.
The publication language controls interface labels and dates.
